## Gaps found vs CLAUDE.md quality bars

1. **Unguarded `.find(...)!` non-null assertion (the headline) — CLAUDE.md
   "No raw array index access / guard with `.find()`, `.at(0)`, or
   destructuring."** Line 9 was:
   `const FULL_STACK_PRICE = SERVICE_TIERS.find((t) => t.slug === "platform")!.setupLabel;`
   The `!` papers over the fact that `.find()` returns `T | undefined`. These
   pages are **statically generated** (`export const metadata` + no dynamic
   params), so if the `"platform"` slug is ever renamed in `pricing.ts` the
   `!.setupLabel` throws `TypeError` **at build time and fails the entire
   site build** — not a localized 404. Replaced with a guarded lookup that
   degrades to a neutral label:
   `?.setupLabel ?? "at a fixed price"`. Behavior is byte-identical today
   (the tier exists → still `"from $9,000"`); the failure mode is now a soft
   copy fallback instead of a build break.

2. **Raw `[0]` index access on a split result — same quality bar +
   `noUncheckedIndexedAccess`.** Line 134 rendered the first sentence of a
   case-study summary via `cs.summary.split(".")[0]`. With
   `noUncheckedIndexedAccess` on, that element is `string | undefined`; React
   tolerates `undefined` as a child so it compiled, but it's the exact raw
   index access the quality bar prohibits, and an empty summary would render
   a bare ".". Replaced with the guarded form
   `cs.summary.split(".").at(0) ?? cs.summary`.

3. **Self-contradicting CTA copy.** The FinalCta heading reads
   "30 minutes. No pitch deck. Just the live demo." while the button directly
   beneath it said "Book a **15**-min intro call" — and the Hero button said
   the same. Every other surface (verticals, builds, FinalCta heading) uses
   **30-min**. Fixed both buttons (Hero + FinalCta) to "Book a 30-min intro
   call" so the page agrees with itself and the rest of the site.
